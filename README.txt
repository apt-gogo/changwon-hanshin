중요
- 현재 버전은 등록 화면과 입력 검증까지만 구현되어 있습니다.
- Supabase 등 서버 DB 저장 기능은 차후 연결 예정입니다.
- 현재 [등록하기]를 누르면 데이터가 저장되지 않고 안내 메시지만 표시됩니다.
- UNIT PLAN은 JavaScript 없이 CSS radio 방식으로 동작합니다.
