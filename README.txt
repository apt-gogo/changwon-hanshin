사용 방법
1. index.html을 브라우저에서 열어 PC 화면을 확인합니다.
2. 휴대폰 화면은 브라우저 개발자도구 또는 실제 서버 업로드 후 확인합니다.
3. GitHub Pages 등 정적 호스팅에 이 폴더의 내용 전체를 업로드하면 됩니다.
